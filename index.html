      감사처분심의위원회에 올릴 결과보고서(파일1)를, 실제 서식 그대로 채워 내보냅니다. 표지 → 1. 총괄 → 2. 일람표 → 3. 지적사항 요약 → 4. 의결사항 → 5. 처분요구(안) 붙임1 → 붙임2 관련근거 순서입니다.

      4단계로 쓰면 됩니다

      1. 문서·감사 기본정보 — 회차·보고일·제목·감사명, 행위 발생일과 인지일을 넣으면 징계시효(3년/5년)를 계산해 배지로 보여 줍니다.
      2. 건별 처분요구·근거 — 처분요구 1건마다 카드를 씁니다. 종류·금액·인원은 총괄표에 자동 합산되고, 5단 블록(제목·경위·사실관계·판단/법령·처분요구)을 적습니다. 사례 DB·규정에서 근거 담기를 누른 것만 인용됩니다.
      3. 세부 증빙표 — 필요한 건에만 표를 채웁니다. 비우면 표 없이 나갑니다.
      4. 미리보기·HWPX — 웹 미리보기로 확인하고 .hwpx를 내려받습니다.
